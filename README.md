# Eternal Rose · 修 bug 闯关

接亲闯关：新郎是软件工程师。打开网页，会看到一束**坏掉的**玫瑰和一段**真的能运行**的代码。
他要亲手把 4 个 bug 修好——每修对一个，玫瑰就好看一点；全部修好，页面就变回那朵完美的、缓缓旋转的玫瑰。

线上地址：**https://yuzhouren2000.github.io/eternal-rose/**

## 玩法（给新郎看）

页面上是一个代码编辑器（`rose.js`）+ 一个测试面板 + 一朵实时渲染的玫瑰。

1. 点右上角的 **运行 ▶**，跑一遍测试（其实打开页面时已经跑过一次了）。
2. 红叉会告诉你哪里坏了。改代码，再点运行。`Cmd/Ctrl + Enter` 也能跑。
3. 4 个测试全绿 → 玫瑰盛开，页面切回原来的样子。

没有提示、没有跳过。测试输出就是线索。

### 埋的 4 个 bug（出题人自己看）

| bug | 症状 | 性质 |
|---|---|---|
| `for (index < centers.length)` | 返回 0 个花心，整束花消失 | 静默 |
| `petalCountOf` 忘了 `return` | 一片花瓣都没有，只剩枯枝 | 静默 |
| `Math.sqrt(4.0)`（应为 `5.0`） | 黄金角变成 180°，花心排成一条直线 | 静默 |
| `requestAnimationFrame(bloomForever())` 多了一对括号 | 爆栈 `RangeError`，花不转 | 当场报错 |

## 当天现场清单

1. **提前用那台 iPad 打开一次** https://yuzhouren2000.github.io/eternal-rose/ 确认是新版本（看到代码编辑器就是新版；如果还是那朵直接盛开的花，说明缓存了旧版，用无痕窗口或在网址后面加 `?v=2` 再开一次）。
2. **横屏**体验更好（竖屏也能玩）。
3. 想更保险：iPad 设置里开「引导式访问」，把他锁在这个页面里。
4. 怕熄屏：代码里已经请求了屏幕常亮（Wake Lock），Safari 16.4+ 支持。
5. 万一游戏出问题，直接开 **/origin.html** 就是最初那朵花（兜底）。

## 重新来一遍

- 每次通关会记住状态，刷新后直达玫瑰。
- 彩排后想清零重玩：打开 `https://yuzhouren2000.github.io/eternal-rose/?fresh=1`
- 想看编辑器但又不想清零：`?edit=1`
- 页面里也有「重置」按钮（连点两次才生效，防误触）。

## 想加小巧思

打开 `index.html`，搜 **`CONFIG`**：

- `successLine`：通关时控制台最后一行。
- `successExtra`：通关时额外打印的一行（默认 `null` 不打印）。
- 想改难度/文案/bug，搜 **`ROSE_MODULE_BUGGY`**（玩家看到的那份代码）和测试部分（搜 `runTests`）。

## 文件

- `index.html` — 整个游戏，单文件，零依赖。
- `origin.html` — 最初那朵玫瑰的存档（兜底用）。
